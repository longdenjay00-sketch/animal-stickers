About the pack

Cut-outs, then history.

Each sticker is a painterly die-cut: thick white border, solid sheet colour, one animal. The five featured cards — lion, golden eagle, Bengal tiger, black stallion, African savanna elephant — carry full lore, measured facts, and known history drawn from IUCN Red List assessments and primary papers. The rest of the pack has shorter field notes.

This is a static HTML, CSS, and JS site. Data lives in data/animals.json. Lore lives in Markdown under lore/. Hosting is GitHub Pages from src/ via Actions; Vercel is the next hop. See GITHUB_PRACTICES.md and HOSTING.md in the repo.
